# Pulse

Pulse is a weekly workout planner for people who want to build their own routine and follow it at their own pace.

## Features

- Plan a workout for each day of the week
- See today's workout as soon as you open the app
- Start with 72 built-in exercises and add your own when needed
- Preview trained muscles on detailed front and back body maps
- Choose a male or female body map
- Give each set group its own reps, weight, and rest time
- Add notes, images, and helpful links to exercises
- Set your exercise order
- Mark exercises as complete while you train
- Back up, import, and export your programme
- Use the app without an internet connection
- Choose from Catppuccin themes and accent colours

## Privacy and license

Pulse has no accounts, ads, analytics, or trackers. See [PRIVACY.md](PRIVACY.md) for details.
